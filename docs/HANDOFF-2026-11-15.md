## 1. Tujuan proyek

Lost & Found UNKLAB adalah portal web komunitas untuk mahasiswa Universitas Klabat melaporkan, mencari, dan mengembalikan barang hilang (*Lost*) maupun barang temuan (*Found*) di lingkungan kampus.

Fase saat ini mencakup:

1. **UI Baru Tema Gelap (SquareUp Figma Dark Theme Adaptation):** Latar gelap `#1A1A1A`, struktur grid berbingkai `#262626`, banner bertekstur gelombang, dan aksen hijau neon `#9EFF00`.
2. **Landing Page Publik (`/`):** Hero topografi, statistik kampus, layanan, preview laporan terbaru, 4 langkah cara kerja, keunggulan, FAQ interaktif, CTA penutup, dan footer.
3. **Login Mahasiswa (`/login`):** **Satu peran saja (`student`)**, dilengkapi banner sambutan, kartu input bergaya SquareUp, checklist fitur akses, show/hide password, dan petunjuk akun demo.
4. **Main Menu / Dashboard Mahasiswa (`/app`):** Header akun terautentikasi, welcome banner dengan kartu highlight temuan minggu ini, 3 kartu statistik (`LOST`, `FOUND`, `TOTAL`), pencarian & filter real-time, grid kartu laporan, serta banner aktivitas komunitas.
5. **Backend Lokal & Database SQLite:** Pondasi autentikasi session cookie dan penyimpanan data untuk pengembangan fitur lanjutan (Task 1–5).

## 2. Keputusan desain dan batasan visual

### Referensi visual

- Desain mengadaptasi template Figma **SquareUp Dark Theme** untuk konteks **Lost & Found UNKLAB**.
- Karakter visual utama: latar karbon gelap (`#1a1a1a`), permukaan kartu gelap (`#1f1f1f` / `#262626`), garis pembatas grid `1px solid #262626`, banner seksi dengan tekstur gelombang (`public/figma/banner-wave-*.png`) dan pola titik (`banner-dots.png`), serta tombol/aksen hijau limau elektrik (`#9eff00`).
- Semua copywriting, konteks lokasi kampus UNKLAB (Student Center, Perpustakaan, Cafeteria, GK1/GK2, Parkiran Fakultas), dan alur klaim tetap orisinal untuk kebutuhan mahasiswa UNKLAB.

### Sistem visual yang sekarang dipakai

| Elemen | Keputusan |
| --- | --- |
| Background utama | `#1a1a1a` (`--bg-dark`) & `#1f1f1f` (`--bg-card`) |
| Garis batas / border | `#262626` (`--grey-15`) & `#333333` (`--grey-20`) |
| Teks utama & sekunder | `#ffffff` (`--white`), `#e6e6e6` (`--grey-90`), `#98989a` (`--grey-60`) |
| Aksi utama / CTA | `#9eff00` (`--green-50`) dengan teks gelap `#262626` (`.sq-btn-lime`) |
| Aksen status | Hijau neon `#9eff00` untuk `Found`, kuning hangat `#ffc470` untuk `Lost` |
| Tipografi utama | `Barlow` (heading, navigasi, statistik, kontrol) & `Inter` (deskripsi & kode) |
| Motion | Transisi halus `0.2s`; menghormati `@media (prefers-reduced-motion: reduce)` |
| Responsif | Breakpoint utama pada `1100px`, `800px`, dan `480px` |

Aturan UX yang wajib dipertahankan:

- Form memiliki label tampak (`.sq-input-label`), pesan error (`.sq-form-error`), `autocomplete`, dan tombol show/hide password (`.sq-password-toggle`).
- Status laporan **wajib selalu menampilkan label teks** (`.sq-status-badge`), bukan hanya warna.
- Jangan menyembunyikan data/fungsi inti di layar mobile.
- Pertahankan focus ring keyboard (`outline: 2px solid var(--green-50)`) dan jangan menambahkan animasi berlebihan.

Detail lengkap sistem desain tersedia di [docs/design-system.md](design-system.md).

## 3. Fitur yang telah selesai

### Frontend

| Rute | Status | Implementasi |
| --- | --- | --- |
| `/` | Selesai | Landing page publik bergaya SquareUp (`LandingPage.jsx`): navbar sticky, hero dengan grafik terrain SVG, statistik kampus, 3 layanan, preview 4 laporan komunitas, 4 langkah cara kerja, 4 keunggulan, 6 FAQ interaktif, CTA banner, dan footer. |
| `/login` | Selesai | Halaman login mahasiswa (`LoginPage.jsx`): navbar, banner sambutan, form `.sq-form-box` dengan kartu input `.sq-input-card`, validasi dasar, error alert, loading state, show/hide password, checklist fitur akses, dan pill kredensial demo. |
| `/app` | Selesai | Dashboard terproteksi (`DashboardPage.jsx`): navbar dengan chip akun & tombol keluar, hero sambutan + highlight temuan minggu ini, 3 kartu statistik (`LOST`, `FOUND`, `TOTAL`), toolbar search & filter tipe, grid `.sq-report-card`, state loading/error/empty, dan banner aktivitas. |

Router sengaja dibuat ringan di `src/router.jsx` memakai History API (`pushState`/`popstate`), bukan `react-router-dom`. Jangan menginstal `react-router-dom`; daftarkan rute baru langsung di `src/App.jsx`.

### Backend

| Endpoint | Status | Perilaku |
| --- | --- | --- |
| `POST /api/auth/login` | Selesai | Menerima `email` dan `password`; mengembalikan profil user dan menyetel cookie session `lf_session`. |
| `POST /api/auth/logout` | Selesai | Menghapus session di memori server dan membersihkan cookie. |
| `GET /api/auth/me` | Selesai | Mengembalikan profil mahasiswa dari sesi aktif; `401` bila tidak login. |
| `GET /api/reports` | Selesai | Mengembalikan daftar laporan dari SQLite; memerlukan session. |

Backend berjalan di port `3001`; Vite melakukan proxy `/api` ke sana melalui `vite.config.js`.

### Database

`server/db.js` membuat database SQLite otomatis di:

```text
server/data/lost-and-found.db
```

File database diabaikan oleh Git. Inisialisasi idempotent membuat tabel berikut:

| Tabel | Tujuan |
| --- | --- |
| `users` | Pengguna mahasiswa dengan email unik dan `password_hash`. |
| `reports` | Barang hilang/ditemukan; berelasi ke `owner_id` pemilik laporan. |
| `claims` | Tabel klaim barang temuan; siap digunakan oleh fitur pengajuan klaim (Task 4). |

Seed awal membuat satu akun mahasiswa (`student@unklab.ac.id`) serta empat contoh laporan.

## 6. Persyaratan dan batasan proyek

1. **Hanya ada satu peran (`student`)** pada fase ini; jangan menambahkan peran atau panel admin.
2. Seluruh halaman baru wajib menggunakan sistem kelas `.sq-*` dan palet warna gelap SquareUp (`--bg-dark`, `--green-50`, font `Barlow` & `Inter`) di `src/styles/global.css`.
3. Frontend hanya boleh memanggil API melalui `src/lib/api.js`; dilarang memanggil `fetch()` langsung di dalam komponen React.
4. Password tidak boleh disimpan atau dikembalikan dalam bentuk plain text.
5. Status laporan wajib selalu memiliki label teks (`.sq-status-badge`).
6. File database lokal (`server/data/lost-and-found.db`), `node_modules`, `.env`, dan `dist` tidak boleh ter-commit ke Git.
